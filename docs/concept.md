# プラレール計算機 — モデル定義

## 計算モデル

- レイアウト: タカラトミー販売のレールだけで構成された、幾何的に矛盾のない配置。
- 分岐レールを **A → B₀, B₁** と表す。状態を i ∈ {0,1} とする。
  - **A 側から進入（対向）**: 列車は B_i へ出る。状態は変わらない（= 読み出し）。
  - **B_j 側から進入（背向）**: 列車は A へ出る。状態は j に更新される（= 書き込み）。
- 列車は **1 編成**。初期位置と向きはレイアウトの一部として与える。
- **入力**: 入力用ポイント群の初期状態。**出力**: 出力用ポイント群の、**停止時点** の状態。
  - 入力ポイントと出力ポイントは兼用しない。入力ポイントが走行中に書き換わることは許す。
  - 補助ポイントの初期状態は設計の一部（定数）として自由に決めてよい。
- 停止: ストップレール（R-08, レバー「停止」）の停止位置に到達したとき。
  - 線路の端に達した場合は「脱線」、状態が繰り返した場合は「停止しない」として、どちらも計算失敗扱い。
  - **別レギュレーション（シミュレータの設定「計算終了の条件」）**: 列車が終端に到達するか、周回軌道に入った（同じ位置・同じポイント状態を再訪した）時点で計算終了とし、その時点の出力を読む。周回中に出力ポイントが変化する場合は計算失敗。
- 研究の主な問い: **実現可能な論理関数の範囲**（最小性より、まず解を 1 つ見つけることを重視）。

## 使用パーツ（第一段階）

| 品番 | 名称 | シミュレータでの形状 |
|---|---|---|
| R-01 | 直線レール | 直線 1L（L = 216mm） |
| R-02 | 1/2直線レール | 直線 L/2 |
| R-03 | 曲線レール | 半径 R・45°（8 本で円）。裏返しで左右両用 |
| R-08 | ストップレール | 直線 1L、中央に停止位置（レバーで停止/通過） |
| R-11 | ターンアウトレール | A から直線 1L（B₀=直進）と曲線 45°（B₁=分岐）。左右 |
| R-11 固定 | R-11 のポイントを固定したもの | 同形状。状態は固定 |
| R-12 | 8の字ポイントレール | A から左曲線（B₀）と右曲線（B₁）の Y 字 |
| R-20 | 1/4直線レール | 直線 L/4。凸凹・凸凸・凹凹 の 3 種 |

## シミュレータ上の仮定（要検証）

1. **R = L（理想化グリッド）**: 曲線の半径を直線 1 本分（216mm）とする。実測では半径 ≒ 214mm とされるが、プラレールはこの理想グリッドで設計されていると見做す。
2. **厳密な接続判定**: 位置は 45° 方向の単位ベクトル e₀..e₃ の整数係数（単位 L/4）で表す。e₀..e₃ は有理数体上一次独立なので、係数の完全一致 ⇔ 幾何的な厳密一致。
3. **凸凹（オス/メス）**: 直線・曲線・ストップは一端が凸・他端が凹。R-11・R-12 は「A が凸・B が凹凹」と「A が凹・B が凸凸」の両方がある（L/R 版で凸凹が逆、かつ裏返し可能なため）。接続は凸と凹の組のみ。
4. **重なり**: 接続していないレールの中心線同士が 38mm 未満に近づいたら、物理的に置けない配置として警告する（立体交差・クロスレールは未対応）。
5. **固定ポイントに開通していない側から進入した場合**: 既定では「そのまま通過（合流）」。設定で「脱線」に切り替えられる。
6. **ビットの割り当て**: R-11 は 直進=0 / 分岐=1、R-12 は（A から見て）左=0 / 右=1。ポイントごとに反転できる。ビットの割り当ては各ポイントの約束事にすぎないので、実現できる関数のクラスは入力・出力の否定について閉じている。

## これまでに分かったこと（メモ）

- **COPY/NOT**: 2 つの R-12 を「目玉」形に向かい合わせると y = ¬x になる（サンプル `NOT`）。ビットの割り当てを変えれば COPY と同じ構成。
- **トグル**: ポイントの B₀ と B₁ をループでつなぐ（リバースループ）と、A から入った列車は状態を反転させ、A 線を逆向きに戻ってくる（サンプル `トグル`）。
- 厳密に閉じるという条件はかなり強い。45° 方向を含む経路には √2 成分が出るため、例えば R-11 2 個による普通の行き違い線は直線だけでは閉じない。目玉の √2 成分は、戻りループに鏡像の「こぶ」を入れて打ち消している。
- **全加算器**: 分岐グラフ形式で与えられたレイアウト（サンプル `全加算器`、R-11 × 20）。列車を A の分岐直前に置き、補助ポイントを S=1・他 0 とすると、「終端到達または周回で終了」のレギュレーションで 8 入力すべてが周回軌道に入り、Co, S が正しく読める。ストップレールで止まる版ではない。
- ターンアウトの B₀ と B₁ は同じ性別なので、両者を結ぶループには凸凸か凹凹の 1/4 直線（R-20）が奇数本必要になる。
